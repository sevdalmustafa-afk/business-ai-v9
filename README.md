# Business AI v10 — Shop & Studio

Mobile-first installable PWA demo for GitHub Pages. Customer-facing digital product catalog, local demo cart, simulated orders, and demo business dashboard.

**No real purchases, payments, fulfillment, autonomous AI agents, private authentication, or server backend.** Do not enter customer information or credentials. All demo data is stored locally in the browser and is not shared across devices.

## Publish on iPhone

Upload `index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest` and `icons/icon.svg` to the repository root, preserving the `icons/` folder. GitHub Pages: deploy from branch `main`, `/(root)`. Open the GitHub Pages URL in Safari, then Share > Add to Home Screen.

For a production shop, implement a secure backend, real authentication, verified payments, legal pages, taxes, privacy, fulfillment, and explicit safeguards before any autonomous purchases.
